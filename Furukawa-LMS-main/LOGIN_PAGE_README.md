# Home Dashboard Page Manual

## Page Name

Home Page / Admin Home Dashboard - Furukawa Learning Management System

## Purpose of This Page

The Home Dashboard gives administrators a complete overview of operators, sections, courses, Dojo hiring, test results, attendance status, efficiency, recent activity, quick actions, and system KPIs.

This page helps the admin monitor training progress, hiring trends, department performance, and operational efficiency from one place.

## Top Statistic Cards

The top section shows four main statistic cards.

1. Total Operators
   - Shows the total number of registered operators.
   - Also shows how many operators are active.
   - Clicking this card opens the operator management page.

2. Total Sections
   - Shows the total number of sections or learning groups.
   - Also shows active or completed sections.
   - Clicking this card opens the departments or sections page.

3. Total Courses
   - Shows the total number of available courses.
   - Also shows how many courses are published.
   - Clicking this card opens the course management page.

4. Dojo Hiring
   - Shows the total number of temporary Dojo candidates.
   - Clicking this card opens the temporary employee list.

## Graph 1 - Dojo Hiring Trend

The Dojo Hiring Trend graph shows how many new Dojo candidates were hired over time.

Main features:

1. Displays hiring count as a column chart.
2. Can show data as Total or By Gender.
3. Gender view separates Male, Female, and Other counts.
4. Supports Daily, Monthly, and Yearly timeframe views.
5. Allows custom From and To date selection.
6. Allows filtering by one or more departments.
7. Shows a summary for Total Hired, Male, Female, and tracked days/months/years.

Use this graph to understand hiring volume and gender distribution over a selected period.

## Graph 7 - Efficiency Analytics

The Efficiency Analytics section shows skill matrix efficiency data for departments, sections, lines, subsections, and individual operators.

This section contains multiple charts:

1. Department Wise Efficiency
   - Shows average efficiency by department.
   - Includes Minimum Efficiency, Total Efficiency, Present Efficiency, and Absent Efficiency.

2. Section Wise Efficiency
   - Shows average efficiency by section.
   - Can be filtered by department, shift, and date.

3. Line Wise Efficiency
   - Shows average efficiency by line.
   - Can be filtered by department, section, shift, and date.

4. Subsection Wise Efficiency
   - Shows average efficiency by subsection.
   - Can be filtered by department, section, line, shift, and date.

5. Operator Wise Efficiency
   - Shows efficiency for individual operators.
   - Uses color to indicate present or absent status.

Common features:

1. Multi-select filters for department, section, line, and shift.
2. From and To date filters.
3. Clear filter option.
4. Show or hide statistics option.
5. Summary capsules for average efficiency and other totals.
6. Loading and empty states when data is unavailable.

Use this section to monitor productivity and skill efficiency across different organization levels.

## How the Home Dashboard Works

1. The admin opens the Home Dashboard.
2. The page records a dashboard view activity in the audit system.
3. The system loads operator, department, course, Dojo, test, attendance, audit, and efficiency data from the server.
4. The top statistic cards show quick totals.
5. The timeline filter can be used to change the date range.
6. Each graph loads its own data and displays filters where required.
7. The admin can click statistic cards or quick actions to open related pages.
8. The Recent Activity card shows the latest audit events.
9. The System Overview card summarizes important KPIs.

---

## Loading, Empty, and Error States

1. Loading State
   - Some cards show skeleton loading placeholders.
   - Some charts show the FME logo with a loading message.

2. Empty State
   - If no data is available, the chart area shows a message such as no data found.
   - The user can adjust filters or date range.

3. Error State
   - If data cannot be loaded, the chart displays a failed-to-load message.

---

## Notes for Users

1. Use the timeline filter first when reviewing dashboard data.
2. Use graph filters to narrow data by department, section, line, shift, worker type, and date.
3. Click statistic cards to open the related management page.
4. Check Test Analytics to review pass and fail performance.
5. Check Efficiency Analytics to monitor productivity and skill performance.
6. Use Quick Actions for common admin work.
7. Review Recent Activity to track system events.

---

## Short Summary

The Home Dashboard is the main admin overview page. It combines statistics, charts, filters, recent activity, quick actions, and system KPIs so administrators can monitor learning, hiring, testing, attendance, and efficiency from one screen.
